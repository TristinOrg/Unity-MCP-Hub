# 项目评估与后续建议

评估日期：2026-10-29。依据当前仓库的源码、测试、构建脚本和文档；未进行真实 Unity Editor 端到端验证。

## 当前优势

- 职责边界清楚：Hub 管理发现、注入、恢复和稳定地址；Unity 工具与实例路由交给 Coplay。
- 临时注入及异常退出恢复机制，比要求用户永久修改 Unity 包配置更容易接受。
- 已有 Windows x64 离线打包流程，对不熟悉 .NET / Python 的 Unity 用户友好。
- 公开地址绑定本机回环接口，避免默认暴露到局域网。

## 建议优先处理

| 优先级 | 发现 | 建议 |
| --- | --- | --- |
| P0 | `MainViewModel.Matches` 只按项目文件夹名匹配 Coplay 实例。同名项目同时打开时，连接状态可能被误判。 | Coplay 提供完整路径或稳定标识时改用该标识；此前在 UI 中提示同名冲突。 |
| P1 | 代理 `HandleAsync` 使用即发即忘任务，关闭时未等待在途请求，也缺少代理协议回归测试。 | 跟踪并等待在途请求；针对 SSE、会话头、取消和上游错误添加集成测试。 |
| P1 | 首次下载 Coplay 包只检查解压后的包名和版本，没有验证下载内容的已知哈希。 | 对固定版本使用可更新的 SHA-256 校验，并在离线构建前复核缓存。 |
| P1 | 端口 9000 / 8080 写死；端口占用会阻断启动。 | 增加端口占用诊断及可配置端口，并同步配置 Unity 集成脚本。 |
| P2 | UI 状态和日志文案只提供英文；当前仓库尚无真实应用截图。 | 增加中英日界面本地化、空列表引导和真实截图；概念宣传图应继续标注为插画。 |
| P2 | 本机 .NET 编译器低于 Avalonia 12.1 分析器要求，构建出现 CS9057 警告。 | 在 CI 固定兼容的 .NET SDK，并确认 Avalonia 包版本组合。 |

## 值得添加的功能

1. **一键复制配置片段：** 除地址外，可复制 Codex TOML 和通用 MCP JSON，减少首次配置步骤。
2. **连接诊断页：** 展示端口、Coplay 版本、健康检查、已连接实例和 Unity Console 排查建议。
3. **项目连接概览：** 清楚展示每个 Editor 的完整路径、PID、连接时间和可执行操作；同名项目加醒目标识。
4. **自动化发布：** CI 运行测试、构建离线 ZIP、生成校验和并附带版本说明；发布后补真实运行截图或短演示。
5. **可选客户端配置向导：** 在用户确认后写入 MCP 客户端配置，并提供回滚。
